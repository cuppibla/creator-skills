# Shorts Playbook — YouTube Shorts

Shorts live in a separate algorithm from long-form. It rewards **immediate retention (first 1–3s)**, **completion %**, and **replays/loopability**. The math is brutal: 50–60% of drop-off happens in the first 3 seconds. Win those 3 seconds or nothing else matters.

## The non-negotiable structure

```
[0.0–2.5s]  HOOK — fully delivered by 2–2.5s. Promise a result/reveal/tension.
[2.5s–end]  BRIDGE — the shortest path from hook to payoff. No detours.
[last 0.5s] PAYOFF that loops — final frame ≈ first frame, so the replay
            feels intentional and completion can exceed 100%.
```

Write the **hook and the payoff first**, in one sentence each. If you can't state both in one line each, the idea isn't tight enough — don't script the middle yet. Everything between is just the bridge connecting them.

## The first second is visual, not verbal

The opening frame has to stop the scroll before a word lands:
- **Pattern interrupt in frame 1** — hard cut, snap-zoom, whip-pan, or a visual mismatch that triggers "wait, what." No slow build, no fade-in.
- **Bold text overlay, sound-off** — first subtitle **≤7 words** (aim 4–7), high contrast, inside top/bottom safe zones. Most viewers see it before they hear it.
- **No logos. No "hey guys." No channel intro.** Those are the #1 cause of the 3-second cliff.
- For tech/教学 specifically (B2B-ish): proof-driven hooks land best — show the *result* or the *data/error on screen* immediately. "This agent booked my flight while I slept" + the screen recording running.

## 节奏 + 卡点 (cut cadence)

Shorts pacing is relentless — but cut to the *idea*, not to a metronome.
- **Cut cadence:** roughly **1–2s per cut** for entertainment energy; education can breathe slightly longer between cuts but still no dead air.
- **No dissolves/transitions in the first 5s** — they read as dead time and tank the 3s hold.
- **Every cut is a 卡点** that should advance the idea or reset attention: new angle, text beat, zoom on the key thing, the before→after flip.
- **The flip** is the strongest single 卡点 in a Short: before/after, wrong-way/right-way, expectation/reality. Place it at the curiosity peak.
- **Waveform check:** no flat spots in the audio. Silence = a swipe.

## Length zones (2026)

Make it as long as the idea needs, then cut 30%. Let her own analytics confirm.
- **15–20s** — single idea, quick tip, visual gag
- **20–35s** — the versatile sweet spot for most tech tips
- **25–40s** — mini-tutorial / structured teaching beat
- **35–60s** — story / transformation, only with strong pacing
- **60–180s** — treat as mini-long-form; only if her data justifies it

Education tolerates **+5–10s** vs entertainment. But a complete short idea beats a padded long one — shorter is only better if the idea still feels whole.

## Loopability — the replay engine

The highest-performing Shorts loop. Design the last 0.5s to visually match frame 1, so the swipe back to the top feels seamless. Or end on a circular line that propels a rewatch: payoff → "but it breaks if you miss X..." → cut to the opening visual of X. Replays push viewed% over 100% and are a primary distribution signal.

## The "next step" — every Short earns its keep

A Short should answer: *if someone likes this, what do they do next?* For Annie that's almost always **→ the long-form video / the channel / the repo.**
- A simple "full build on my channel" CTA converts Shorts traffic into long-form session watch time, which the main algorithm loves.
- Map each Short to a long-form topic deliberately — Shorts are the top of the funnel into her series, not standalone confetti.

## Semantic alignment (2026 Gemini update)

YouTube now reads Shorts content semantically. Title + description + on-screen text should all orbit **one** keyword intent. Don't phrase the concept three different ways across the three surfaces — pick the term (e.g. "ADK memory", "agent that remembers") and keep it consistent so the seed audience is the right one.

## Shorts hook checklist (run before publishing)

- [ ] First subtitle ≤7 words, readable sound-off
- [ ] Hook fully delivered by 2.5s
- [ ] Pattern interrupt in frame 1, no fade-in
- [ ] No "hey guys" / logo / slow build in first 5s
- [ ] No dissolves in first 5s
- [ ] Payoff stated; last 0.5s loops to frame 1
- [ ] First draft cut by ~30%, no audio flat spots
- [ ] Clear next step (→ long-form / channel / repo)
- [ ] Title + on-screen text + description share one keyword
